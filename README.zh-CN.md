# TermPilot

[English](README.md) | [简体中文](README.zh-CN.md)

TermPilot 将 SSH 终端、远程桌面和服务器管理集中在一个应用中，提供 macOS、Windows、Android、iPhone 与 iPad 客户端。

## 主要功能

- **SSH 连接**：快速连接、多会话、终端搜索、密码/密钥/证书认证和代理连接；桌面端还提供本地终端与分屏。
- **主机管理**：嵌套分组、凭证复用、连接历史和主机笔记。
- **文件传输**：SFTP 文件浏览、上传、下载、编辑、权限管理和文件断点续传；桌面端还支持 SCP。
- **远程桌面**：VNC、RDP 与 Apple 高性能屏幕共享，按平台与协议提供剪贴板和文件共享；移动端支持触控、缩放与平移。
- **批量任务**：桌面端可面向多台 Linux/macOS 主机执行命令或脚本、上传与采集文件，支持后台执行和历史结果查询。
- **服务器工具**：系统状态、进程监控和 Docker 管理，需要远端具备相应工具与权限。
- **AI 助手**：使用自行配置的模型服务，按服务器独立对话，结合终端上下文辅助操作，并提供工具执行审批。
- **常用工具**：本地、远端与动态端口转发，常用脚本和命令片段。
- **备份与同步**：密码保护的备份，以及可选的 WebDAV、S3 兼容存储、Cloudflare R2 加密同步，支持扫码添加设备。同步功能处于预览阶段，默认关闭。
- **界面体验**：简体中文与英文、深浅主题，以及手机和平板布局。

各平台的功能范围有所不同，Windows 与 Android 的 Apple 高性能屏幕共享仍处于预览阶段。
