# TermPilot Swift

[English](README.md) | [简体中文](README.zh-CN.md)

TermPilot Swift 是一款面向 macOS 的原生终端与 SSH 工作台。它将主机管理、远程连接、文件传输和服务器运维集中在一个应用中，适合需要同时维护多台服务器的开发者与运维人员。

## 主要功能

- **终端与 SSH**：支持本地 Shell、快捷连接和已保存主机，以及密码、私钥、证书、SSH Agent 和代理等认证方式。
- **多会话工作区**：支持标签页、水平/垂直分屏、拖拽排序、合并、分离、复制、固定及安全恢复布局。
- **高效终端操作**：提供搜索、复制粘贴、链接识别、连接日志，以及命令、参数、历史记录和本地/远程路径补全。
- **主机集中管理**：支持嵌套分组、批量操作、外观标记、凭据复用、代理配置和严格的主机密钥校验。
- **SFTP/SCP 文件管理**：支持浏览、上传、下载、编辑、移动、复制、重命名、权限修改及可暂停的并发传输。
- **服务器运维**：提供系统概览、进程管理和 Docker 容器/镜像管理。
- **常用工具**：支持本地/远程/动态端口转发、脚本、命令片段、主机笔记及连接历史。
- **数据备份**：可导出和导入密码保护的 `.tpbackup` 加密备份。

## 版本优势

- **原生 macOS 体验**：使用 Swift 6、SwiftUI 和 SwiftTerm 构建，界面、菜单、快捷键及窗口行为与系统一致。
- **本地优先**：主机、工作区和偏好设置均保存在本机，不依赖云服务。
- **安全存储**：敏感凭据使用 AES-GCM 加密；独立管理 `known_hosts`，密码不会写入终端日志或工作区快照。
- **完整工作流**：从连接服务器、传输文件到查看进程和管理容器，无需频繁切换工具。
- **双架构与双语支持**：支持 Apple Silicon、Intel Mac，以及简体中文和英文界面。

## 环境要求

- macOS 14 或更高版本
- Xcode 26 或 Swift 6.2 工具链
- 首次构建需要联网下载锁定版本的 Node.js 22 SSH 运行时

## 开发

```bash
swift test
swift run TermPilot
```

构建 Universal 2 应用：

```bash
./scripts/build-app.sh
open dist/TermPilot.app
```

应用数据默认保存在 `~/Library/Application Support/TermPilot/`。工作区快照不会保存终端输出、进程状态或明文密码。
