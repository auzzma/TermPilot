# TermPilot UI/UX 优化任务清单

## 阶段一：核心基础与高频体验重构（高优先级 P0）
*此阶段聚焦于解决视觉割裂感、统一跨平台规范，以及优化最高频的用户连接路径。*

### 任务 1：统一跨平台设计规范与色彩令牌系统 (Design System Sync)
- **具体目标与预期成果**：彻底消除硬编码色值，实现 Tauri 与 Swift 端 `ColorScheme` 的完美对齐；解决浅色模式下 ANSI 颜色不可见的致命缺陷。
- **实施步骤**：
  1. 建立 `design-system.md`，定义标准 Semantic Tokens（如 `--bg-elevated`, `--text-primary`，并统一 6px 圆角规范）。
  2. 在 Tauri 侧全局排查并替换所有硬编码颜色（如 `#0d1117` 等），移除通过透明度模拟层级的 CSS。
  3. 拦截 `xterm.js` 的渲染流，引入 WCAG 2.1 AA 对比度算法：当检测到浅色背景（如 `#f6f8fa`）时，自动下调高亮 ANSI 颜色的亮度。
  4. 解除 `store.ts` 中针对浅色模式的强制深色锁定（`dark` 回滚为 `system`）。
- **所需资源与负责人员**：UI/UX 设计师（1名）、Swift 开发工程师（1名）、Tauri/React 开发工程师（1名）。
- **完成时间节点**：第 1 周内完成。
- **KPIs**：全局 CSS 文件中硬编码 `#HEX` 色值数量降至 0；浅色模式下终端所有文本与背景的对比度 ≥ 4.5:1。
- **依赖关系**：无。此任务是后续所有 UI 修改的前置依赖。

### 任务 2：QuickConnect 快捷连接流改造
- **具体目标与预期成果**：降低用户对鼠标的依赖，实现全键盘操作的“即搜即连”，提升连接效率。
- **实施步骤**：
  1. 全局绑定 `Cmd/Ctrl + K` 快捷键，触发 QuickConnect Sheet 弹窗。
  2. 引入模糊搜索库（如 Fuse.js），对现有主机列表进行实时过滤。
  3. 在 QuickConnect 默认视图中增加“最近连接 (Recent)”列表。
  4. 确保键盘上下键可切换选中项，回车键直接发起连接。
- **所需资源与负责人员**：Tauri/React 开发工程师（1名）。
- **完成时间节点**：第 2 周。
- **KPIs**：从唤起弹窗到发起连接的平均耗时缩短至 2 秒以内；键盘导航 100% 覆盖弹窗元素。
- **依赖关系**：需等待任务 1 的圆角与毛玻璃动画规范落地。

## 阶段二：信息架构与响应式布局（中优先级 P1）
*此阶段旨在解决信息过载问题，优化窗口在各种尺寸下的自适应表现。*

### 任务 3：信息架构重组（渐进式展开与扁平化）
- **具体目标与预期成果**：降低新手用户的配置门槛，使得 `HostEditorView` 和 `SettingsView` 界面更加清爽直观。
- **实施步骤**：
  1. **重构 HostEditorView**：仅保留名称、IP、端口、认证方式为默认展示；将代理桥接（Proxy Bridge）、端口转发（Port Forwarding）等移入名为“高级设置”的折叠面板（Accordion）。
  2. **重构 SettingsView**：废弃现有的深层导航，改为“左侧菜单（常规/外观/终端/同步） + 右侧内容”的经典布局。
- **所需资源与负责人员**：Swift 开发工程师（1名）。
- **完成时间节点**：第 3 周。
- **KPIs**：新建主机页面的必填项/可见项比例提升至 80% 以上；全局设置任意配置项的触达点击数 ≤ 2 次。
- **依赖关系**：无强依赖，可与 Tauri 端任务并行。

### 任务 4：工作区自适应与多窗格重排 (Adaptive Workspace)
- **具体目标与预期成果**：保障用户在小屏幕或多窗格分割时的终端可用性，实现优雅的界面降级。
- **实施步骤**：
  1. 为 `TerminalSessionSidePanel`（左侧边栏）增加拖拽改变宽度的 Handle，并设定 200px 为默认值。
  2. 监听窗口尺寸变化，当宽度 < 800px 时，左侧边栏自动折叠为仅图标模式或隐藏。
  3. 优化终端分屏逻辑：窗口缩小时触发终端网格（Grid）的等比缩放计算，防止 `xterm.js` 布局崩溃。
- **所需资源与负责人员**：Tauri/React 开发工程师（1名）。
- **完成时间节点**：第 4 周。
- **KPIs**：快速拉伸窗口时引发的布局崩溃（Crash/UI Overlap）次数为 0；侧边栏收起/展开帧率保持在 60fps。
- **依赖关系**：依赖任务 1 中规范的布局间距变量。

### 任务 5：高级交互增强（无缝拖拽与上下文菜单）
- **具体目标与预期成果**：完善对 `WorkspacePaneDragHandlers` 的应用，提升多会话管理的直观性。
- **实施步骤**：
  1. 在主机拖拽至分组时，绘制一条 2px 蓝色的目标指示线（Drop Indicator）。
  2. 拖拽终端 Tab 进行分屏时，渲染半透明的占位遮罩（Placeholder Mask）。
  3. 为主机列表、终端 Tab 增加统一的右键菜单（集成复制 IP、关闭其他标签等功能）。
- **所需资源与负责人员**：Swift 开发工程师（1名）、Tauri/React 开发工程师（1名）。
- **完成时间节点**：第 5 周。
- **KPIs**：拖拽交互的单元测试覆盖率达到 100%；无幽灵拖拽元素残留 bug。
- **依赖关系**：依赖任务 4 的响应式网格系统。

## 阶段三：动效反馈与细节打磨（低优先级 P2）
*此阶段为锦上添花，旨在通过微交互赋予软件“生命力”。*

### 任务 6：状态反馈与微动效注入 (Micro-animations)
- **具体目标与预期成果**：提升操作的即时确认感，利用动效无侵入地传递系统状态。
- **实施步骤**：
  1. 为全局按钮、输入框的 `hover`/`active` 状态添加统一的 CSS 过渡（`transition: all 0.15s ease-out`）。
  2. 改造延迟指示器：在 SSH “连接中”状态时，呈现黄色呼吸灯（Pulsing）效果；连接成功瞬间转为常亮绿色。
  3. 拦截终端的 Bell (BEL) 字符控制符，在应用静音状态下触发终端边框 0.2 秒的白色/反色闪烁（Visual Bell）。
- **所需资源与负责人员**：Tauri/React 开发工程师（1名）。
- **完成时间节点**：第 6 周。
- **KPIs**：动效执行期间不产生显著的 CPU 峰值（< 5% 增长）；用户操作的视觉响应时间 < 50ms。
- **依赖关系**：需在任务 1（色彩规范）和任务 2（连接流）完全稳定后进行。

### 任务 7：图标库统一化替换 (Iconography Swap)
- **具体目标与预期成果**：解决跨平台环境下的图标风格不一致问题。
- **实施步骤**：
  1. 在 Tauri 侧移除零散的 SVG，全局引入 Lucide Icons 或与 SF Symbols 风格高度相似的图标库。
  2. 统一图标属性：Stroke Width = 1.5px，ViewBox = 24x24。
- **所需资源与负责人员**：UI/UX 设计师（1名）、Tauri 开发工程师（1名）。
- **完成时间节点**：第 6 周。
- **KPIs**：全应用图标风格 100% 统一，无模糊或像素不对齐的图标。
- **依赖关系**：可随时穿插进行，优先级最低。
