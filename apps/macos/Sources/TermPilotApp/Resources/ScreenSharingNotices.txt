TermPilot — Source and Licenses

The shared Rust connection engine implements SSH, SFTP/SCP, proxy transports,
VNC, and Apple high-performance screen sharing. Native media decoding uses
Apple VideoToolbox and AudioToolbox through a statically linked Swift adapter.
The application does not bundle or launch Node.js or Python.

Apple protocol code derives from iShareScreen by renegadelink:
https://github.com/renegadelink/iShareScreen

High-performance scope: macOS, local network, one 1920 × 1080 SDR virtual
screen, one active session. High-performance application proxies and Windows
high-performance media remain unavailable. Standard VNC uses the Rust engine
on both platforms.
