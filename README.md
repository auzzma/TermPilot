# TermPilot

[English](README.md) | [简体中文](README.zh-CN.md)

TermPilot brings SSH terminals, remote desktops and server management into one app, with clients for macOS, Windows, Android, iPhone and iPad.

## Features

- **SSH connections**: Quick Connect, multiple sessions, terminal search, password/key/certificate authentication and proxies. Desktop clients also offer local terminals and split panes.
- **Host management**: Nested groups, reusable credentials, connection history and host notes.
- **File transfers**: SFTP browsing, uploads, downloads, editing and permission management, with resumable file transfers. Desktop clients also support SCP.
- **Remote desktops**: VNC, RDP and Apple high-performance Screen Sharing, with clipboard and file sharing where supported. Mobile clients provide touch controls, zoom and pan.
- **Batch jobs**: Desktop tools for running commands and scripts, uploading files and collecting files across Linux/macOS hosts, with background execution and result history.
- **Server tools**: System status, process monitoring and Docker management on hosts with the required tools and permissions.
- **AI assistance**: Per-server conversations using a configured model provider, terminal context and tool-execution approvals.
- **Workflow tools**: Local, remote and dynamic port forwarding, saved scripts and command snippets.
- **Backups and sync**: Password-protected backups and optional encrypted sync through WebDAV, S3-compatible storage or Cloudflare R2, including QR-code device setup. Sync is a preview feature and is off by default.
- **Interface**: English and Simplified Chinese, light/dark themes, and phone and tablet layouts.

Feature availability varies by platform. Apple high-performance Screen Sharing remains in preview on Windows and Android.
